# LA AGUJA Rescue Disk 1.0.1

Rescue Disk maintenance update; Flash Imager remains 1.0.0 and the standalone preparation skill remains 1.1.0.

- Interactive Check → update list → per-item No / Yes · RAM / Yes, persistent → review → apply → final Back to menu.
- Measured download/APT progress plus explicit preparation, installation, USB saving, verification and next-boot activation stages. No automatic reboot or premature success screen.
- RAM-only checks, separate temporary installations and exact selected-package/provider persistence. Full Rescue releases require persistence.
- A saved pending generation remains the next clean build base. Manifest-verified public updater files carry over, never the credential-bearing RAM overlay.
- Graphical local VT and terminal/SSH fallback share the same selection plan; local VT identity survives the updater's scoped sudo re-execution.

See [the installed update guide](../runtime/UPDATES.md) and [live-updates skill](../skills/live-updates/SKILL.md). Validation evidence and illustrated usage are recorded with the completed release, not inferred from source tests alone.
