Von außen arbeiten eröffnet neue Möglichkeiten.

Fällt das installierte System aus, sind oft auch seine Werkzeuge nicht mehr erreichbar. La Aguja startet ein unabhängiges Linux vom USB-Stick, um Hardware und Datenträger zu untersuchen.

Die KI läuft in diesem Linux, nicht in der Firmware oder vor jedem Betriebssystem. Sie ist vom Windows oder Linux unabhängig, das du retten, ersetzen oder vorbereiten willst.

Ein Agent kann dein Anliegen verstehen, den Zustand prüfen und Werkzeuge ausführen, statt nur Befehle zu erklären. Das Ergebnis hängt von Hardware, Datenzustand und Vorgehen ab.

Was heute verfügbar ist

Eine Arbeitsgrundlage, keine automatische Lösung für jeden Defekt. Codex CLI und OpenCode sind enthalten; Claude Code und Antigravity lassen sich optional integrieren. Cloud-KI braucht Internet und dein Anbieterkonto.

Das Problem verstehen

Datenträger, Partitionen, Speicher, Geräte und Ausfallzeichen prüfen. Startprobleme von einem sich verschlechternden Laufwerk unterscheiden.

Retten und kopieren

Mit ddrescue, TestDisk, PhotoRec oder rsync Images erstellen, Dateien suchen und Daten kopieren. Vollständige Rettung ist nicht garantiert.

Am System arbeiten

Dateien und Einstellungen ohne Systemstart untersuchen. Werkzeuge für Partitionen, Boot, Linux und Windows sind vorhanden; jede Reparatur braucht Zustands- und Kompatibilitätsprüfungen.

Einen Neustart vorbereiten

Werkzeuge für Linux-Installationen und Windows-Images bilden die Grundlage für angeleitete Abläufe. Kein Universalinstaller und kein enthaltenes Windows/WinPE.

Was daraus entstehen könnte

Die Unabhängigkeit vom installierten System eröffnet mehr als Rettung. Das sind mögliche Entwicklungsrichtungen, keine heutigen Automatikfunktionen oder zugesagte Roadmap.

Passende Installationen

Partitionen, Pakete und Einstellungen auf Hardware und Bedarf abstimmen. Vollständige Abläufe und Tests je System fehlen noch.

Auf einen anderen Rechner umziehen

Daten und Einstellungen ohne Start des alten Systems übertragen. Anwendungen, Rechte und Treiber brauchen gezielte Anpassung.

Ein System als virtuelle Maschine erhalten

Ein Datenträgerimage als Ausgangspunkt nutzen. Boot, Treiber, Lizenzen und Aktivierung müssen gelöst werden; Kopieren allein reicht nicht.

Vorher auf einer Kopie testen

Änderungen auf Kopien oder virtuellen Maschinen erproben und vergleichen. Nicht jeder Hardwaredefekt und jeder Eingriff lassen sich simulieren.

Arbeitsumgebungen wiederherstellen

Reproduzierbare Profile und Datensicherungen kombinieren, auch für mehrere Rechner. Dafür braucht es Validierung, Geheimnisverwaltung und Kontrollen je Gerät.

Mehr Möglichkeiten bedeuten mehr Verantwortung.

Der Agent kann volle Rechte am Rechner erhalten. „Nur ansehen“ ist keine technische Schreibsperre. Vor Änderungen Zieldatenträger bestimmen, Plan prüfen und irreversible Schritte freigeben.

Eine wiederherstellbare Sicherung auf einem anderen Medium, Arbeit auf Kopien und Ergebnisprüfung gehören dazu. Ein fehlerfreier Befehl beweist weder intakte Dateien noch einen erfolgreichen Systemstart.

La Aguja umgeht keine Verschlüsselung: BitLocker und LUKS benötigen den richtigen Schlüssel. Eine Live-Sitzung ist weder zertifizierte Forensik noch eine Vertrauensgarantie für kompromittierte Rechner.

Bei Cloud-KI können übermittelte Daten und Anweisungen den Rechner verlassen, abhängig vom Anbieter. Teile bewusst, ohne Schlüssel und Zugangsdaten. Klassische Werkzeuge arbeiten auch offline; Cloud-KI nicht.

Dateien können bösartige Anweisungen an den Agenten enthalten. Sie sind zu untersuchende Daten, keine Befehle oder Erlaubnis, über die vereinbarte Aufgabe hinauszugehen.

Vor dem Start

Müssen Windows oder Linux noch funktionieren?

Nein. Du startest das Linux von La Aguja per USB. Hardware und Start vom Medium müssen kompatibel sein.

Werden interne Datenträger beim Start verändert?

Sie werden nicht automatisch eingehängt oder repariert. Werkzeuge und Agenten können sie später verändern. Das Beschreiben des Vorbereitungs-USB ist ein eigener Vorgang und löscht diesen USB.

Geht es ohne Internet?

Lokale Werkzeuge ja. Cloud-KI braucht Netzwerk und dein Konto oder Zugangsmittel; ein lokales Modell ist nicht enthalten.

Ist Fernzugriff nötig?

Nein. Du kannst direkt am Rechner arbeiten. SSH im LAN oder deinem Tailscale/Headscale ist optional; LA AGUJA betreibt keine Fernkonsole.

Funktioniert es auf jedem Rechner?

Die aktuelle Version ist experimentell und für x86-64 gedacht. Hardware, Boot, Secure Boot und Verfahren prüfen; eine universell signierte Secure-Boot-Kette wird nicht angeboten.
