Working from outside changes what is possible.

When the installed system fails, many of its tools become unavailable. La Aguja takes another route: it boots an independent Linux from USB, letting you inspect hardware and work with disks from there.

The AI runs inside that Linux, not in firmware or before every operating system. The difference is that it does not depend on the Windows or Linux you want to recover, replace or prepare.

An agent can interpret your request, check the computer’s state and run tools. It can take part in the work, not just explain commands. Results depend on hardware, the condition of the data and how each operation is performed.

What you have today

A working foundation, not an automatic fix for every fault. Codex CLI and OpenCode are included; Claude Code and Antigravity integrations are optional. Cloud AI needs a connection and your own provider account.

Understand the problem

Inspect disks, partitions, memory, devices and signs of failure. Tell a boot problem apart from a drive that is deteriorating.

Recover and copy

Use ddrescue, TestDisk, PhotoRec or rsync to image disks, look for files and copy data. A damaged drive may not allow full recovery.

Work on the installed system

Inspect files and configuration without booting it. Partition, boot, Linux and Windows tools are available; each repair requires compatibility and state checks.

Prepare a fresh start

Tools can prepare Linux installations and work with Windows images. They support guided procedures, not a universal installer or an included Windows/WinPE environment.

What this foundation could become

Not relying on the installed system opens uses beyond rescue. These are possible areas for development, not automatic features in today’s release or a committed roadmap.

Tailored installations

Prepare a system for its hardware and its user: partitions, packages and settings. Complete workflows and testing for each system are still needed.

Move to another computer

Transfer data and configuration without requiring the old system to boot. Applications, permissions and drivers need specific adaptation.

Keep an old system as a virtual machine

Use a disk image to try to preserve an existing environment. Boot, drivers, licensing and activation need to be resolved; copying alone is not enough.

Test before changing the original

Try changes on a copy or virtual machine and compare results. Not every hardware fault or operation can be simulated.

Rebuild environments instead of starting over

Combine reproducible profiles and data backups to restore a working environment or prepare several computers. This needs validation, secret management and per-computer controls.

More capability brings more responsibility.

An agent can gain full permissions on the computer. Asking it to “only look” is not a technical write lock. Before changing a disk, identify the target, review the plan and authorise irreversible operations.

A recoverable backup on another device, working on an image where possible and checking results are part of the job. A command finishing without errors does not prove that files are intact or that the system will boot.

La Aguja does not bypass encryption: BitLocker and LUKS require the correct key. A live session is not certified forensic evidence, nor does it guarantee that a compromised computer is trustworthy.

With cloud AI, instructions and data you provide may leave the computer under the provider’s terms. Decide what to share and keep keys and credentials out. Traditional tools can work offline; cloud AI cannot.

Files on the computer can also contain malicious instructions aimed at the agent. They must be treated as data to examine, not commands or permission to go beyond the agreed task.

Before you start

Must Windows or Linux still work?

No. You boot La Aguja’s Linux from USB. You do need compatible hardware and a computer that can boot from that media.

Does it change internal disks at boot?

It does not mount or repair them automatically. Tools and agents can change them afterwards. Writing the preparation USB is a separate operation that erases that USB.

Does it work without Internet?

Local tools do. Agents using cloud AI need networking and your own account or credential; no local model is included.

Is remote access required?

No. Work directly on the computer. SSH over LAN or your Tailscale/Headscale is optional; LA AGUJA does not host a remote console.

Will it work on any computer?

The current release is experimental and targets x86-64. Check hardware, boot, Secure Boot and procedure compatibility; no universal signed Secure Boot chain is offered.
