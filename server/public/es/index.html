Trabajar desde fuera cambia las posibilidades.

Cuando el sistema instalado falla, muchas de sus herramientas dejan de estar disponibles. La Aguja entra por otra vía: arranca un Linux independiente desde el USB y, desde ahí, permite examinar el hardware y trabajar con los discos.

La IA funciona dentro de ese Linux, no en el firmware ni antes de cualquier sistema operativo. La diferencia es que no depende del Windows o Linux que quieres recuperar, sustituir o preparar.

El agente puede interpretar lo que le pides, consultar el estado del equipo y ejecutar herramientas. No se limita a explicarte comandos: puede participar en el trabajo. El resultado depende del hardware, del estado de los datos y de cómo se haga cada intervención.

Lo que tienes hoy

Una base de trabajo, no una reparación automática de cualquier avería. Codex CLI y OpenCode están incluidos; Claude Code y Antigravity tienen integración opcional. La IA en la nube requiere conexión y tu cuenta del proveedor.

Entender el problema

Examinar discos, particiones, memoria, dispositivos y señales de fallo. Separar un problema de arranque de un disco que se está dañando.

Recuperar y copiar

Usar ddrescue, TestDisk, PhotoRec o rsync para crear imágenes, buscar archivos y copiar datos. Un disco dañado no garantiza una recuperación completa.

Trabajar sobre el sistema

Examinar archivos y configuraciones sin arrancar el sistema instalado. Hay herramientas de particiones, arranque, Linux y Windows; cada reparación exige comprobar compatibilidad y estado.

Preparar un nuevo comienzo

Hay herramientas para preparar instalaciones Linux y trabajar con imágenes Windows. Son una base para procedimientos guiados, no un instalador universal ni Windows/WinPE incluido.

Lo que esta base permite construir

No depender del sistema instalado abre usos que van más allá del rescate. Estas son líneas de desarrollo posibles, no funciones automáticas de la versión actual ni una hoja de ruta comprometida.

Instalaciones a medida

Preparar un sistema según el hardware y lo que necesita la persona: particiones, paquetes y configuración. Faltan flujos completos y pruebas para cada sistema.

Migrar a otro equipo

Trasladar datos y configuraciones sin exigir que el equipo antiguo arranque. Adaptar aplicaciones, permisos y controladores requiere trabajo específico.

Conservar un sistema como máquina virtual

Partir de una imagen del disco para intentar mantener un entorno antiguo. Arranque, controladores, licencias y activación deben resolverse; no basta con copiarlo.

Probar antes de tocar el original

Ensayar cambios sobre una copia o una máquina virtual y comparar el resultado. No todo fallo físico ni toda operación se pueden simular.

Reconstruir entornos, no empezar de cero

Combinar perfiles reproducibles y copias de datos para recuperar un entorno de trabajo o preparar varios equipos. Harían falta validación, gestión de secretos y controles por equipo.

Más capacidad también significa más responsabilidad.

El agente puede obtener permisos completos sobre el equipo. Una petición de «solo mirar» no es un bloqueo técnico de escritura. Antes de cambiar un disco, hay que identificar el destino, revisar el plan y autorizar las operaciones irreversibles.

Una copia recuperable en otro medio, trabajar sobre una imagen cuando sea posible y comprobar el resultado forman parte del trabajo. Una orden terminada sin errores no demuestra que los archivos estén bien ni que el sistema vaya a arrancar.

La Aguja no rompe el cifrado: BitLocker y LUKS necesitan la clave correcta. Tampoco convierte una sesión live en una prueba forense certificada ni garantiza que un equipo comprometido sea fiable.

Al usar IA en la nube, las instrucciones y los datos que le entregues pueden salir del equipo según el proveedor. Decide qué compartir y no envíes claves ni credenciales. Las herramientas tradicionales pueden trabajar sin Internet; la IA en la nube, no.

Los archivos del equipo también pueden contener instrucciones maliciosas dirigidas al agente. Deben tratarse como datos que analizar, no como órdenes ni permisos para hacer más de lo acordado.

Antes de empezar

¿Necesito que Windows o Linux funcionen?

No. Arrancas el Linux de La Aguja desde el USB. Sí necesitas hardware compatible y que el equipo pueda iniciar desde ese medio.

¿Toca los discos internos al arrancar?

No los monta ni los repara automáticamente. Las herramientas y el agente sí pueden modificarlos después. Grabar el USB de preparación es otra operación y borra ese USB.

¿Funciona sin Internet?

Las herramientas locales sí. Los agentes que usan servicios IA en la nube necesitan red y tu propia cuenta o credencial; no se incluye un modelo local.

¿Tengo que usar acceso remoto?

No. Puedes trabajar en el propio equipo. SSH por LAN o por tu Tailscale/Headscale es opcional; no hay una consola remota alojada por LA AGUJA.

¿Sirve para cualquier ordenador?

La versión actual es experimental y está orientada a x86-64. Compatibilidad de hardware, arranque, Secure Boot y procedimiento deben comprobarse; no hay una cadena universal firmada para Secure Boot.
