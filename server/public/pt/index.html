Trabalhar por fora abre outras possibilidades.

Quando o sistema instalado falha, muitas ferramentas ficam inacessíveis. La Aguja inicia um Linux independente pelo USB para examinar hardware e trabalhar com discos.

A IA funciona dentro desse Linux, não no firmware nem antes de qualquer sistema operativo. Não depende do Windows ou Linux que pretende recuperar, substituir ou preparar.

O agente pode compreender o pedido, consultar o estado e executar ferramentas, não apenas explicar comandos. O resultado depende do hardware, dos dados e de cada intervenção.

O que está disponível hoje

Uma base de trabalho, não uma reparação automática de qualquer avaria. Codex CLI e OpenCode incluídos; Claude Code e Antigravity com integração opcional. IA na nuvem exige ligação e conta própria do fornecedor.

Compreender o problema

Examinar discos, partições, memória, dispositivos e sinais de falha. Distinguir problemas de arranque de um disco que se degrada.

Recuperar e copiar

Usar ddrescue, TestDisk, PhotoRec ou rsync para criar imagens, procurar ficheiros e copiar dados. Recuperação completa não é garantida.

Trabalhar no sistema

Examinar ficheiros e configurações sem o iniciar. Existem ferramentas para partições, arranque, Linux e Windows; cada reparação exige verificar estado e compatibilidade.

Preparar um novo começo

Ferramentas para instalações Linux e imagens Windows apoiam procedimentos guiados. Não há instalador universal nem ambiente Windows/WinPE incluído.

O que se pode construir sobre esta base

Não depender do sistema instalado permite ir além do resgate. São possibilidades de desenvolvimento, não funções automáticas atuais nem um roteiro comprometido.

Instalações à medida

Preparar partições, pacotes e definições para o hardware e a pessoa. Faltam fluxos completos e testes por sistema.

Mudar de computador

Transferir dados e configurações sem iniciar o sistema antigo. Aplicações, permissões e controladores precisam de adaptação específica.

Preservar um sistema numa máquina virtual

Partir de uma imagem de disco para tentar manter um ambiente. Arranque, controladores, licenças e ativação não se resolvem apenas com uma cópia.

Testar antes de alterar o original

Experimentar alterações numa cópia ou máquina virtual e comparar. Nem toda falha física ou operação pode ser simulada.

Reconstruir ambientes de trabalho

Combinar perfis reproduzíveis e cópias de dados, também para vários computadores. Exige validação, gestão de segredos e controlo por equipamento.

Mais capacidade traz mais responsabilidade.

O agente pode obter permissões completas. Pedir «só olhar» não bloqueia tecnicamente a escrita. Identifique o disco, reveja o plano e autorize operações irreversíveis.

Cópia recuperável noutro suporte, trabalho sobre imagem quando possível e verificação fazem parte da intervenção. Um comando sem erros não prova integridade dos ficheiros nem arranque do sistema.

La Aguja não contorna a encriptação: BitLocker e LUKS exigem a chave correta. Uma sessão live não é perícia certificada nem garantia de confiança num computador comprometido.

Na IA cloud, dados e instruções enviados podem sair do computador conforme o fornecedor. Escolha o que partilha, sem chaves ou credenciais. Ferramentas tradicionais funcionam offline; IA cloud não.

Os ficheiros também podem conter instruções maliciosas para o agente. São dados a analisar, não ordens nem autorização para ir além da tarefa acordada.

Antes de começar

Windows ou Linux precisam de funcionar?

Não. Inicia o Linux de La Aguja pelo USB. Precisa de hardware compatível e capacidade de arrancar por esse suporte.

Altera discos internos ao arrancar?

Não os monta nem repara automaticamente. Ferramentas e agentes podem alterá-los depois. Gravar o USB de preparação é uma operação distinta que apaga esse USB.

Funciona sem Internet?

As ferramentas locais sim. IA cloud exige rede e conta ou credencial própria; não há modelo local incluído.

Acesso remoto é obrigatório?

Não. Pode trabalhar no próprio computador. SSH por LAN ou Tailscale/Headscale próprio é opcional; LA AGUJA não aloja consola remota.

Funciona em qualquer computador?

A versão atual é experimental e destina-se a x86-64. Verifique hardware, arranque, Secure Boot e procedimento; não existe cadeia universal assinada para Secure Boot.
