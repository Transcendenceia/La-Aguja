Uma plataforma de lançamento, não apenas um salva-vidas.

LA AGUJA transforma um PC compatível em uma oficina Linux antes de iniciar o sistema instalado, mesmo com o disco vazio. Dê uma missão ao agente: construir, configurar, experimentar, migrar ou recuperar.

A sessão live usa uma camada gravável em RAM sobre a imagem USB somente leitura. É Linux, não firmware, e o USB inteiro não é copiado para RAM. Os discos internos ficam intactos ao iniciar; você decide quando usá-los para gravação.

Inclui clientes de IA com acesso root, SSH, Python, Git, ferramentas de discos, debootstrap e arch-install-scripts. Amplie com pacotes compatíveis: QEMU/KVM, motores de contêineres e ferramentas de compilação exigem instalação adicional, RAM/armazenamento suficientes e hardware compatível. Salve os resultados importantes explicitamente; a RAM é temporária. IA na nuvem exige rede e sua conta; não há modelo local incluído.

Quando o sistema existente precisa voltar

Ferramentas poderosas. Limites claros.

Os agentes podem ter acesso root completo. O modo Safe pede confirmação para usar ferramentas; o YOLO é mais autónomo. Nenhum é um ambiente isolado, um bloqueador de escrita ou uma autorização para ultrapassar o seu pedido.

Faça uma cópia de segurança antes de alterar qualquer coisa. Um comando bem-sucedido não prova que os ficheiros estão intactos ou que o sistema consegue arrancar. BitLocker e LUKS exigem a chave correta do proprietário; LA AGUJA não contorna a encriptação.

A IA na nuvem pode receber as instruções e os dados que partilhar, segundo os termos do fornecedor. Trate os ficheiros que contêm instruções como dados não fiáveis e nunca cole segredos numa instrução de recuperação.

Antes de começar

É apenas um disco de recuperação?

Inicie um Linux independente pelo USB e coloque agentes de IA para trabalhar: instalar sistemas, configurar servidores, criar um laboratório virtual ou recuperar dados. Um sistema instalado funcionando é opcional. Seu próximo projeto, não.

Windows ou Linux precisam de funcionar?

Não. Inicia o Linux de La Aguja pelo USB. Precisa de hardware compatível e capacidade de arrancar por esse suporte.

Altera discos internos ao arrancar?

Não os monta nem repara automaticamente. Ferramentas e agentes podem alterá-los depois. Gravar o USB de preparação é uma operação distinta que apaga esse USB.

Funciona sem Internet?

As ferramentas locais sim. IA cloud exige rede e conta ou credencial própria; não há modelo local incluído.

Acesso remoto é obrigatório?

Não. Pode trabalhar no próprio computador. SSH por LAN ou Tailscale/Headscale próprio é opcional; LA AGUJA não aloja consola remota.

Funciona em qualquer computador?

A versão atual é experimental e destina-se a x86-64. Verifique hardware, arranque, Secure Boot e procedimento; não existe cadeia universal assinada para Secure Boot.
