从系统之外工作，打开新的可能。

已安装系统发生故障时，它的许多工具也无法使用。La Aguja 从 U 盘启动独立的 Linux，借此检查硬件并操作磁盘。

AI 在这个 Linux 中运行，不在固件中，也不是在所有操作系统之前运行。它不依赖你想恢复、替换或准备的 Windows 或 Linux。

智能体可以理解请求、检查电脑状态并运行工具，而不只是解释命令。结果取决于硬件、数据状况和具体操作方式。

当前具备的能力

这是工作基础，不是能自动修复所有故障的工具。包含 Codex CLI 和 OpenCode；Claude Code、Antigravity 为可选集成。云端 AI 需要联网及你自己的服务商账户。

了解问题

检查磁盘、分区、内存、设备和故障迹象，区分启动故障与正在损坏的磁盘。

恢复与复制

使用 ddrescue、TestDisk、PhotoRec 或 rsync 创建磁盘镜像、查找文件和复制数据。无法保证完整恢复。

处理已安装系统

不启动系统即可检查文件和配置。提供分区、启动、Linux 和 Windows 相关工具；每次修复都要核实兼容性和状态。

准备重新开始

Linux 安装工具及 Windows 镜像工具可支持有指导的操作流程，但不是通用安装器，也不包含 Windows/WinPE 环境。

以此为基础，还可以开发什么

不依赖已安装系统，意味着用途可以超越救援。以下是可能的发展方向，不是当前版本的自动功能，也不是已承诺的路线图。

按需求安装

针对硬件和个人需求准备分区、软件包和配置。各系统仍需完整流程与测试。

迁移到另一台电脑

无需启动旧系统即可转移数据和配置。应用、权限与驱动仍需专门适配。

将旧系统保留为虚拟机

从磁盘镜像出发，尝试保留原有环境。启动、驱动、许可证和激活都要解决，复制本身并不够。

先测试，再修改原盘

在副本或虚拟机中尝试更改并对比结果。不是所有硬件故障或操作都能模拟。

重建工作环境

结合可复现配置与数据备份，恢复工作环境或准备多台电脑。还需要验证、秘密信息管理和逐机控制。

能力越大，责任越大。

智能体可以获得电脑的完整权限。“只查看”的要求并不是技术上的写保护。修改磁盘前，应确认目标、审查计划并授权不可逆操作。

在其他介质上保留可恢复备份，尽可能操作副本，并检查结果，这些都是工作的一部分。命令成功不代表文件完好，也不代表系统能够启动。

La Aguja 不绕过加密：BitLocker 和 LUKS 需要正确密钥。Live 会话不等同于经认证的取证，也不能保证已被入侵的电脑可信。

使用云端 AI 时，提供的数据和指令可能按服务商规则离开电脑。应决定分享哪些内容，不要发送密钥或凭据。传统工具可以离线工作，云端 AI 不行。

电脑文件也可能包含针对智能体的恶意指令。应将其视为待分析的数据，而不是命令或超出约定任务的授权。

开始之前

Windows 或 Linux 必须正常运行吗？

不需要。你从 U 盘启动 La Aguja 的 Linux。但硬件必须兼容，并能从该介质启动。

启动时会修改内部磁盘吗？

不会自动挂载或修复内部磁盘。之后的工具和智能体可以修改磁盘。写入准备 U 盘是另一项操作，会清除该 U 盘。

没有互联网也能使用吗？

本地工具可以。云端 AI 需要网络和你自己的账户或凭据；不包含本地模型。

必须远程访问吗？

不需要，可以直接在电脑上操作。局域网或自己的 Tailscale/Headscale 上的 SSH 为可选项；LA AGUJA 不托管远程控制台。

所有电脑都能使用吗？

当前版本为实验性版本，面向 x86-64。需要确认硬件、启动、Secure Boot 和操作流程兼容性；不提供通用签名的 Secure Boot 启动链。
