01

我的计算机无法启动

先了解故障，再尝试修复。

  1. 记录最近一次更改，并按型号、序列号和容量识别每块磁盘。
  2. 检查健康状态并整理设备清单。如果磁盘正在发生故障，应优先将其制作成镜像，保存到独立的存储设备上。
  3. 备份重要文件，提出范围明确的修复方案，并验证结果。

遇到以下情况请停止： 目标不明确、磁盘状况恶化，或没有可用于恢复的备份。

02

我需要取出自己磁盘上的文件

保护源盘，将恢复的数据存到别处。

  1. 确认所有权，并在需要时取得相应的加密恢复密钥。
  2. 检查分区，选择合适的只读方式，或先制作镜像。
  3. 将数据恢复到另一个设备，并打开有代表性的文件进行验证。

遇到以下情况请停止： 即将把恢复的文件保存到源磁盘上。

03

我想检查一台计算机

开展便携式诊断，无须先决定安装系统。

  1. 取得许可，并记录硬件和固件信息。
  2. 检查存储设备的健康状态、内存和网络设备；避免给可疑磁盘施加负载。
  3. 将报告保存到外部设备，并在选择硬件升级方案或操作系统之前列出尚不确定的事项。

遇到以下情况请停止： 拟议的测试会写入数据、更改固件，或超出所有者的授权范围。

可选工作流程

一个 USB，多种重新出发的可能。

这些是授权工作中的思路，并非自动功能或成功案例。每项计划都需要检查硬件、准备独立备份，并约定操作范围。

01 / 黑匣子

更新出错之后

从你自己的系统安装中收集启动日志和配置，保留副本，并在提出回滚方案前对照最近一次已知更改。

02 / 便携实验室

让翻新电脑重获新生

为获赠的计算机整理清单，评估存储设备的健康状态，并规划轻量级系统。兼容性和许可仍需检查。

03 / 家庭诊所

提供帮助，不混淆家人的文件

每次只处理一台已获授权的计算机。为每位所有者使用独立的保存位置，解释计划，交付可读取的文件，而不是承诺。

04 / 无显示器家庭实验室

从隔壁房间使用终端

配置 SSH 和可选的私有网络，以便从另一台计算机检查服务器。必须先确保 USB 启动、网络可达性和身份验证正常工作。

05 / 丢失的项目

找到消失的文件夹

在你自己的磁盘或镜像中搜索源文件、项目名称和已知文件类型。尽可能保留时间戳，并将恢复的数据保存到别处。

06 / 购买之前

更有针对性地检查硬件

经卖方许可，对照所报告的组件、存储设备健康状态和接口。简短的诊断并不等于质量保证，也不是完整的压力测试。

07 / 音频工作室

工作站沉默了，创作会话还在

在你自己的磁盘上查找音频会话、采样素材和插件清单。先复制；应用程序许可和项目兼容性需要另行验证。

08 / 迷你数据中心

一组小型设备，一套审慎方法

逐一清点节点，记录网络和存储方面的证据，并基于副本规划修复。绝不能将一台主机的操作许可视为整个设备群的授权。

强大的工具，明确的边界。

智能体可能拥有完整的 root 权限。Safe 模式会要求确认工具操作；YOLO 模式更为自主。两者都不是沙箱，不会阻止写入，也不意味着可以超出你的请求范围。

更改任何内容之前先备份。命令执行成功，并不能证明文件完好无损或系统能够启动。BitLocker 和 LUKS 需要所有者提供正确的密钥；LA AGUJA 不会绕过加密。

云端 AI 可能按照服务商条款接收你分享的提示词和数据。应将包含指令的文件视为不可信数据，绝不要将秘密信息粘贴到恢复提示词中。

开始之前

Windows 或 Linux 必须正常运行吗？

不需要。你从 U 盘启动 La Aguja 的 Linux。但硬件必须兼容，并能从该介质启动。

启动时会修改内部磁盘吗？

不会自动挂载或修复内部磁盘。之后的工具和智能体可以修改磁盘。写入准备 U 盘是另一项操作，会清除该 U 盘。

没有互联网也能使用吗？

本地工具可以。云端 AI 需要网络和你自己的账户或凭据；不包含本地模型。

必须远程访问吗？

不需要，可以直接在电脑上操作。局域网或自己的 Tailscale/Headscale 上的 SSH 为可选项；LA AGUJA 不托管远程控制台。

所有电脑都能使用吗？

当前版本为实验性版本，面向 x86-64。需要确认硬件、启动、Secure Boot 和操作流程兼容性；不提供通用签名的 Secure Boot 启动链。
